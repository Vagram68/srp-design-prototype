# SRP — интерактивный прототип

38 экранов приложения для компьютера и телефона. Каталог экранов, сценарии, формы и оригинальные видео SRP.

Это демонстрационный дизайн для согласования. Запись, вход, настройки и уведомления не подключены к рабочему SRP.

## Просмотр

Откройте `index.html` или опубликуйте корень репозитория через GitHub Pages. Сохраняйте папку `media` рядом с HTML.

## Публикация

Используйте отдельный репозиторий только в личном аккаунте владельца. Не используйте организацию Core Lab или её репозитории. В настройках Pages выберите источник «Deploy from a branch», ветку main и папку / (root).
