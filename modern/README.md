# SRP — обновление прежнего дизайна

Вариант для согласования двух экранов: главная и расписание турниров.
Откройте index.html#home или index.html#tournaments. Светлая тема — light.html.
Остальные разделы и действия сохранены из предыдущего прототипа. Данные демонстрационные, сервер не подключён.
Главная сохраняет прежний видеобаннер, карточки турниров, лиги и карту.
Турниры: выбор даты в одну кнопку, группировка по дням, понятное время и статус, подробности и запись рядом.
Сохранены поиск, типы турниров, мои записи, участники, структура, запись и отмена.
