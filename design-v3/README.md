# SRP — федеральная платформа, концепт для согласования

Откройте index.html. Прямая главная: prototype/index.html?theme=dark#home. Светлая: ?theme=light#home.
На компьютере переключатели находятся сверху. На телефоне приложение адаптируется автоматически, тема доступна в настройках профиля; ?review=on показывает панель согласования.

42 маршрута: 38 из предыдущего прототипа и новые Игры / Смотреть / Вся Россия / Найди пары.
Это предложение нового направления, без Figma. Существующие данные — демонстрационные.
Мини-игра работает локально, как и её рекорд и напоминание о видео.
Пуши, настоящие трансляции, каталог внешних соревнований, сетевой игровой сервис и ИИ требуют интеграции.

Обоснование и следующий этап: concept-notes.html.
Проверки: prototype/verification.json — логика в синтетическом DOM, layout-verification.json — браузерные размеры 42 страниц × 2 темы × 2 размера.
