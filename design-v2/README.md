# SRP Clubhouse — дизайн приложения игроков

Дата: 8 октября 2026.

Открыть index.html — обзор. prototype/index.html — интерактивный прототип; handoff.html — спецификация. Можно запустить `python3 -m http.server 8765` из этой папки и открыть http://127.0.0.1:8765/.

## Комплект
- 38 маршрутов, desktop/mobile, две темы. Каталог экранов и сценарии в панели прототипа. На телефоне для панели согласования добавить `?review=on`.
- Формы, запись/отмена, история, рейтинг, публичные профили, достижения, структура и рассадка, настройки, трансляция, клубы и лиги.
- Предложения сверх действующего SRP: помощник, план поездки, календарь, расширенные настройки пушей. Интеграции не подключены.
- page-specs.json: цель, функции, состояния и контракт каждой страницы. tokens.json: цвета и геометрия. research.md: источники и аудит. usability-test.md: план 5–7 сеансов; ещё не проведены.
- Исходные видео и логотип сохранены в media.

## Figma
https://www.figma.com/design/gXy7fwsV4HKG4T3vUxKdQ6
76 исходных редактируемых экранов, основы и кнопки. Лимит MCP Starter остановил финальную компонентную сборку. figma-import — локальный вспомогательный плагин продолжения; синтаксис проверен, запуск и результат не проверены. HTML — актуальный источник последних визуальных исправлений.

## Перед внедрением
Гостевые формы регистрации/восстановления сверить с рабочим приложением. Уточнить серверные правила записи, отмены, статусы будущих лиг, формулу рейтинга, координаты/адреса и доступность контента клубов. Полные официальные юридические документы подключить из SRP. Возрастные требования не предположены.

## Проверено
38 маршрутов и 152 общих состояния в сценарном тесте. Регистрация/отмена, поиск, клубы, этапы лиг, анкета трансляции, 32 уровня проверенного примера структуры. Браузерная проверка адаптива и контраст базовых пар цветов. Проверка синтаксиса не заменяет API-интеграцию и реальные тесты с игроками.
